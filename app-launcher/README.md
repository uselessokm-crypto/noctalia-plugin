# App Launcher

A Noctalia plugin that provides quick access to launch your custom applications directly from the launcher.

## Features

- Add custom applications with name, command, and icon
- Search and launch apps from the Noctalia launcher
- Easy configuration through the plugin settings
- Uses system icons from your icon theme

## Usage

1. Open Noctalia settings and find the App Launcher plugin
2. Add your applications with:
   - **Name**: Display name (e.g., "Terminal")
   - **Command**: Launch command (e.g., "wezterm")
   - **Icon**: Icon name from your system theme (e.g., "terminal")
3. Open the launcher (typically Alt+Space or similar)
4. Type to search and press Enter to launch

## Configuration

The plugin stores your configured applications in the plugin settings. Each application has:
- `name`: Display name in the launcher
- `command`: Shell command to execute
- `icon`: Icon name from the system icon theme
